# Bank Marketing
Project Overview

This project uses a Decision Tree Classifier to predict whether a customer will subscribe to a bank term deposit based on marketing campaign data.

The dataset contains customer demographic information, financial details, and previous campaign interactions. The machine learning model helps banks identify potential customers who are more likely to subscribe, improving marketing efficiency and reducing campaign costs.

Objective

The main objective of this project is to:

Analyze customer data from bank marketing campaigns
Build a Decision Tree classification model
Predict customer subscription behavior
Evaluate model performance using accuracy metrics
